# الأرشيف الوزاري العراقي

موقع ثابت يعمل على GitHub Pages ولا يحتاج API لتشغيل البحث أو عرض الحلول.

## التشغيل على GitHub
1. ارفع محتويات هذا المجلد إلى المستودع (Repository).
2. من Settings ثم Pages اختر Deploy from a branch.
3. اختر الفرع `main` والمجلد `/ (root)` ثم Save.
4. افتح رابط GitHub Pages بعد اكتمال النشر.

## إضافة الأسئلة
افتح `data/questions.json` وأضف كل سؤال كعنصر داخل المصفوفة. مثال على بنية البيانات:

```json
[
  {
    "id": "sample-001",
    "grade": "الثالث متوسط",
    "subject": "الفيزياء",
    "chapter": "الفصل الأول",
    "kind": "عرّف",
    "text": "اكتب نص السؤال هنا",
    "answer": "اكتب الحل النموذجي الكامل هنا",
    "appearances": [
      {"year": 2021, "round": "الدور الأول"},
      {"year": 2024, "round": "الدور الثاني"}
    ]
  }
]
```

- `grade`: الثالث متوسط أو السادس العلمي أو السادس الابتدائي.
- `subject`: اسم المادة كما يظهر في قائمة الموقع.
- `chapter`: اسم الفصل أو `موضوعات عامة / غير محدد`.
- `appearances`: أضف سنة ودوراً لكل ظهور موثّق؛ لا تكتب نطاق سنوات.
- احذف المثال التوضيحي قبل النشر، ولا تضف سؤالاً إلا بعد التحقق من مصدره.

## ملاحظات
- قاعدة البيانات حالياً فارغة عمداً؛ لا توجد أسئلة أو تكرارات وهمية.
- الثيم الافتراضي أسود وذهبي.
- عرض الأسئلة والبحث والفلاتر والحلول يعمل محلياً من ملفات الموقع دون API.
- نظام Premium الآمن للتحقق من الاشتراك وحفظه عبر الأجهزة يحتاج خدمة عضويات/خلفية؛ لا تضع مفاتيح سرية داخل JavaScript أو ملفات JSON العامة.
